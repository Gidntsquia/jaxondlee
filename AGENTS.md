# Repo facts
- Vite + React + TS + Chakra UI. `npm run dev`, `npm run build`. Deployed on Vercel.
- Projects: `src/data/projects.ts`; images in `public/`. Skill tags must exist in `src/entities/Skill.ts` and `src/data/skills.ts`.
- Theme colors are semantic tokens in `src/theme.ts` (paper, panel, ink, muted, squid, line).
- Lint already had errors before this work (hook called in a callback in ProjectCard).
